### 🚀 Featured Projects

#### 🧪 [LLM Eval Pipeline](https://github.com/bpurva05/llm-eval-pipeline)
> Python · OpenAI API · GitHub Actions · Docker · SQLite

An automated testing system that replaces manual QA of LLM features. Every prompt change is scored against a hand-labeled golden dataset with concurrent LLM-as-judge eval runs, then diffed against prior runs using configurable warning and critical thresholds, plus rolling-window drift detection that catches gradual degradation per-run checks miss. It posts PR comments, sends Slack alerts, publishes HTML diff reports, and blocks merges on critical regressions.

---

#### ☁️ [Cloud-Native Web App on AWS](https://github.com/bpurva05/webapp_fork)
> FastAPI · PostgreSQL · Terraform · Packer · GitHub Actions · AWS

A full-stack cloud application owned end to end, from REST API and PostgreSQL data model design to provisioning the entire AWS stack as code: EC2 Auto Scaling behind an ALB, RDS Multi-AZ, S3, Route 53, and CloudWatch. Multi-account GitOps CI/CD promotes builds from DEV to DEMO with health-check gating, and an event-driven SNS → Lambda verification flow uses DynamoDB idempotency for exactly-once delivery, secured by KMS, Secrets Manager, ACM TLS, and least-privilege IAM.
